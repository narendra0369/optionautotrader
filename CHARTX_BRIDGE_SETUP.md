# Staged CHARTX bridge
Do not deploy to an active trading worker. Target is OPTIONX read-only Render backend, currently `optionx-v7-offline-test-staging`. Deploying or changing its environment resets its RAM session, so schedule maintenance only if safe and reverify the owner Angel login on the original OPTIONX HTTPS page. Add `CHARTX_BRIDGE_ENABLED=1` and `CHARTX_DATA_ACCESS_KEY` equal to the private CHARTX access key, never paste in chat. The bridge verifies HMAC and timestamp before looking up only the configured owner session; uses fixed official instrument master and historical API. No login, account data, token export, order route, or trading changes. Test: `python -m unittest -v live_v7.test_chartx_ohlc_bridge`. Actual broker data not verified. Check broker market-data permissions. No automatic deployment of this branch.
